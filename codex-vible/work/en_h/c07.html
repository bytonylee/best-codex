Part 3: Core features in depth

Automation

What is automation?

Codex Automation = letting Codex follow your instructions, regularly inspect your project, find issues, and handle them according to rules.

This is like having an "AI on-call engineer" for your project:

It does not interrupt you in normal times, it reminds you when there is a problem, it tries to fix simple issues first, and finally lets you review and decide.

How to use automation

For example, a "weekly automatic Codex session review" can make Codex more useful over time.

You can ask Codex to inspect recent session records, task results, and common issues on a schedule, then organize them into a reusable workflow profile.

Use a prompt like this:

Please retrieve and review the Codex session records and execution logs from the past week, and maintain a “Codex session review and personal style profile.”

Requirements:
1. Prioritize any available session-history retrieval capability; if logs need to be read, only perform search, metadata extraction, and extraction of relevant snippets. Do not load large session files in full.
2. Do not reproduce raw logs, private content, keys, internal reasoning, or long original conversations.
3. Summarize execution lessons: which practices caused problems, what the final correct approach was, and which scenarios it is suitable to reuse in.
4. Summarize my preferences: UI design preferences, product philosophy, interaction principles, content-system preferences, and workflow preferences.
5. Organize a reusable rule checklist: rewrite the review conclusions into concise rules that later Codex sessions can follow.
6. When updating the document, deduplicate and merge similar rules, and keep the date range or task type as source clues.
7. If there are rules suitable for long-term reuse, suggest whether to add them to project-level or user-level AGENTS.md.

Plugins

Additional "capability packages" installed for Codex.

What are plugins?

Codex can already read code, modify code, and run commands. Plugins add connections to more tools, fixed workflows, or specialized capabilities.

Examples:

Plugin type What it lets Codex do
Chrome Plugin Open web pages, inspect pages, and debug with the browser
Gmail Plugin Summarize emails and draft replies
Google Drive Plugin Read documents, spreadsheets, and slides
Slack Plugin Summarize channel messages and draft team replies
Security Plugin Check code for security issues
Computer Use Plugin Operate applications on the computer

How plugins, Skill, and MCP relate to each other (read this table first)

Plugins, Skill, and MCP are the three concepts in this part that are easiest to confuse. They do not replace one another; each manages a different layer. Use the overview table below first. Later sections will not repeat this comparison.

Comparison Plugin Skill MCP
In one sentence A capability installation package A fixed working method An interface for connecting external tools
What problem it solves Installing, packaging, and distributing capabilities "How to do" similar tasks "What tool or data to connect to"
Scope Largest; can package Skill, MCP, and other pieces Smaller; the workflow for one type of task A connection to a single external tool or data source
Analogy A toolbox The manual inside the toolbox The socket that powers the toolbox
Who uses it Ordinary users can also install it with one click Ordinary users can also use it More oriented toward developer and team configuration
Examples GitHub Plugin, Figma Plugin README Skill, code review Skill Database MCP, documentation MCP

Keep one sentence in mind: Plugins can package Skill and MCP into capability packages that are easier to install; Skill manages "how to do it," and MCP manages "what tool to connect to."

How to install plugins in Codex App

Open Codex App

Search or browse plugins

You can also search for the plugin you need.

Open the plugin details

Click Add to Codex or the add button

Open a new thread after installation to use it

How to install plugins in Codex CLI

Go to the project directory, then start Codex:

codex

Then enter the following command in Codex CLI:

/plugins

After you open the plugin list, you can:

Action Description
Search for Plugins Find the plugin you need
View details Check what the plugin can do and what permissions it needs
Install plugin Install the plugin
Uninstall plugin Uninstall the plugin
Space Enable or disable installed plugins
