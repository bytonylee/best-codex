Codex CLI installation and getting started

Codex CLI is Codex for the command line.

Use it if you are comfortable opening a terminal, such as PowerShell, Terminal, iTerm, or Windows Terminal.

macOS / Linux installation

On macOS, you usually install it one of two ways.

Method 1: Install with npm

First, check that Node.js is installed on your computer.

Open Terminal and run:

node -v
npm -v

If version numbers appear, Node.js and npm are available.

Then install Codex CLI:

npm install -g @openai/codex

After installation, verify it:

codex --version

You can also run it directly:

codex
Method 2: Install with Homebrew

Mac users can use Homebrew instead:

brew install --cask codex

After installation, run:

codex

For beginners:

  • If you already have Node.js installed, use npm.
  • If you are already used to Homebrew, use brew.

Windows installation

On Windows, use PowerShell or Windows Terminal.

Step 1: install Node.js.

After installation, open PowerShell and run:

node -v
npm -v

If version numbers appear, the installation succeeded.

Step 2: install Codex CLI:

npm install -g @openai/codex

Step 3: verify the installation:

codex --version

You can also run it directly:

codex

On first use in Windows, do not run Codex in a system directory.

Do not work directly in these locations:

C:\
System directory
Desktop
Downloads folder
Important files folder

Create a practice directory instead:

D:\AI-Codex-Projects\hello-codex

First run

After installation, run this in the terminal:

codex

On first run, Codex will prompt you to log in.

Codex CLI usually supports two login methods:

1. Log in with a ChatGPT account
2. Log in with an OpenAI API Key

Beginners should start with the first option: logging in with a ChatGPT account.

Method 1: Log in with a ChatGPT account

This is the simplest option for regular users and beginners.

Run this in the terminal:

codex

Or:

codex login

Then select:

Sign in with ChatGPT

The login flow usually works like this:

1. Enter codex or codex login in the terminal
2. Choose Sign in with ChatGPT
3. The browser automatically opens the login page
4. Enter your ChatGPT account
5. After login succeeds, the browser sends the login result back to the terminal
6. Return to the terminal, and Codex CLI is ready to use
Method 2: Log in with an API Key

Codex CLI also supports logging in with an OpenAI API Key.

API Key login fits developers, automation scripts, CI/CD, server tasks, and similar uses.

Beginners can think of it this way:

ChatGPT login = uses your ChatGPT account and plan quota
API Key login = uses OpenAI Platform API billing

To log in with an API Key, first create an API Key in OpenAI Platform.

Then set the environment variable in the terminal.

On macOS / Linux, use:

export OPENAI_API_KEY="your_API_Key"
printenv OPENAI_API_KEY | codex login --with-api-key

In Windows PowerShell, use:

$env:OPENAI_API_KEY="your_API_Key"
$env:OPENAI_API_KEY | codex login --with-api-key

After login succeeds, Codex CLI saves your login information. Later, run:

codex

You can keep using it after that.

What is the difference between ChatGPT login and API Key login?
Comparison ChatGPT account login API Key login
Best for Regular users and beginners Developers, automation, CI/CD
Quota usage Depends on your ChatGPT plan Billed through the OpenAI Platform API
Learning curve Simpler Slightly more complex
Recommended for beginners Recommended Not recommended at first
Good for local practice Yes Also possible, but unnecessary
Good for automation scripts Average Better suited
API Key login precautions

An API Key is sensitive. Do not leak it.

Do not put an API Key in these places:

In code
Send it to others
Expose it in screenshots
Upload it to GitHub
Put it in README
Put it in a frontend web page
Commit it to a Git repository

If you accidentally leak an API Key, go to OpenAI Platform immediately and delete or regenerate it.

API Key login is convenient for automation, but billing follows API usage. Beginners should not run long tasks until they understand the cost rules.

Check current login status

Use the command below to check whether you are currently logged in:

codex login status

If you need to log out, run:

codex logout

After logging out, you must log in again the next time you run Codex CLI.
