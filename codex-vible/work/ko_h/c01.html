이 글은 2026-06-22에 접근할 수 있었던 Codex App, Codex CLI, Codex IDE Extension, Codex Web / Cloud의 공개 기능과 실제 테스트한 화면을 기준으로 작성했습니다. Codex는 빠르게 업데이트되므로 설치 방법, 모델 이름, 한도, 진입 위치, 명령 매개변수는 모두 바뀔 수 있습니다. 구체적인 기능과 가격은 OpenAI 공식 문서, 현재 Codex 버전, 계정에 실제로 표시되는 내용을 기준으로 확인해 주세요.

0. 이용 안내

0.1 중요 고지

  • 이 자료는 비공식 가이드이며 OpenAI 공식 문서를 대변하지 않습니다.
  • 모든 기능은 OpenAI 공식 문서와 실제 Codex 버전을 기준으로 합니다.
  • 이 PDF는 Codex 업데이트에 맞춰 계속 유지 관리됩니다.
  • GitHub 리포지토리의 최신 Markdown 원고를 먼저 확인하는 것을 권장합니다.

0.2 이 PDF가 적합한 독자

  • Codex를 전혀 써 본 적은 없지만 체계적으로 시작하고 싶은 사람.
  • 코드는 작성할 수 있지만 Codex를 실제 프로젝트에 연결하는 방법을 모르는 사람.
  • 이미 Cursor, Claude Code, ChatGPT를 사용해 보았고 Codex 워크플로를 비교하고 싶은 사람.
  • 독립 개발자, AI 도구 블로거, 기술 팀 책임자.
  • AI 프로그래밍 워크플로, 지식 베이스, 자동화 프로세스를 구축하고 싶은 사람.

0.3 읽기 경로

  • 빠른 시작 경로: 0. 이용 안내 → 1부: 먼저 Codex가 무엇인지 이해하기 → 2부: 설치, 설정과 환경 준비 → 4부: 표준 워크플로 → 5부: 실전 사례 모음
  • 개발자 핵심 경로: 1부: 먼저 Codex가 무엇인지 이해하기 → 2부: 설치, 설정과 환경 준비 → 3부: 핵심 기능 자세히 보기 → 4부: 표준 워크플로
