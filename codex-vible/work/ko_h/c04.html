Codex CLI 설치와 시작하기

Codex CLI는 명령줄에서 쓰는 Codex입니다.

PowerShell, Terminal, iTerm, Windows Terminal 같은 터미널 사용에 익숙한 사람에게 적합합니다.

macOS / Linux 설치

macOS에서는 보통 두 가지 방법으로 설치합니다.

방법 1: npm으로 설치하기

먼저 컴퓨터에 Node.js가 설치되어 있는지 확인하세요.

Terminal을 열고 다음을 실행합니다.

node -v
npm -v

버전 번호가 보이면 Node.js와 npm을 사용할 수 있습니다.

그다음 Codex CLI를 설치합니다.

npm install -g @openai/codex

설치가 끝나면 정상적으로 설치됐는지 확인합니다.

codex --version

또는 바로 실행합니다.

codex
방법 2: Homebrew로 설치하기

Mac 사용자는 Homebrew를 사용할 수도 있습니다.

brew install --cask codex

설치 후 실행합니다.

codex

초보자에게는 다음 방식을 권장합니다.

  • 이미 Node.js를 설치했다면 npm을 사용합니다.
  • 이미 Homebrew에 익숙하다면 brew를 사용합니다.

Windows 설치

Windows에서는 PowerShell 또는 Windows Terminal을 사용하세요.

첫 번째 단계는 Node.js 설치입니다.

설치가 끝나면 PowerShell을 열고 다음을 실행합니다.

node -v
npm -v

버전 번호가 보이면 설치가 성공한 상태입니다.

두 번째 단계에서는 Codex CLI를 설치합니다.

npm install -g @openai/codex

세 번째 단계에서는 정상적으로 설치됐는지 확인합니다.

codex --version

또는 바로 실행합니다.

codex

Windows에서 처음 사용할 때는 시스템 디렉터리에서 Codex를 실행하지 마세요.

다음 위치에서 바로 작업하지 마세요.

처음 실행하기

설치가 끝나면 터미널에서 다음을 실행합니다.

codex

처음 실행하면 Codex가 로그인을 안내합니다.

Codex CLI는 보통 두 가지 로그인 방식을 지원합니다.

1. ChatGPT 계정으로 로그인
2. OpenAI API Key로 로그인

초보자에게는 첫 번째 방식인 ChatGPT 계정 로그인을 먼저 권장합니다.

방법 1: ChatGPT 계정으로 로그인하기

일반 사용자와 초보자에게 가장 단순한 방식입니다.

터미널에서 다음을 실행합니다.

codex

또는 다음을 실행합니다.

codex login

그다음 이 항목을 선택합니다.

Sign in with ChatGPT

로그인 흐름은 보통 다음과 같습니다.

1. 터미널에 codex 또는 codex login 입력
2. Sign in with ChatGPT 선택
3. 브라우저가 자동으로 로그인 페이지 열기
4. ChatGPT 계정 입력
5. 로그인에 성공하면 브라우저가 로그인 결과를 터미널로 전달
6. 터미널로 돌아오면 Codex CLI를 사용할 수 있음
방법 2: API Key로 로그인하기

Codex CLI는 OpenAI API Key 로그인도 지원합니다.

API Key 로그인은 개발자, 자동화 스크립트, CI/CD, 서버 작업에 더 적합합니다.

초보자는 이렇게 이해하면 됩니다.

ChatGPT 로그인 = ChatGPT 계정과 요금제 한도를 사용
API Key 로그인 = OpenAI Platform API 과금 사용

API Key로 로그인하려면 먼저 OpenAI Platform에서 API Key를 만듭니다.

그다음 터미널에서 환경 변수를 설정합니다.

macOS / Linux에서는 이렇게 작성합니다.

export OPENAI_API_KEY="your_API_Key"
printenv OPENAI_API_KEY | codex login --with-api-key

Windows PowerShell에서는 이렇게 작성합니다.

$env:OPENAI_API_KEY="your_API_Key"
$env:OPENAI_API_KEY | codex login --with-api-key

로그인에 성공하면 Codex CLI가 로그인 정보를 저장합니다. 이후에는 다음을 다시 실행합니다.

codex

계속 사용할 수 있습니다.

ChatGPT 로그인과 API Key 로그인은 무엇이 다른가요?
비교 ChatGPT 계정 로그인 API Key 로그인
적합한 사용자 일반 사용자, 초보자 개발자, 자동화, CI/CD
사용 한도 ChatGPT 요금제와 관련 OpenAI Platform API 기준 과금
시작 난이도 더 간단함 조금 더 복잡함
초보자에게 권장 여부 권장 처음부터 사용은 권장하지 않음
로컬 연습에 적합 적합 가능하지만 꼭 필요하지 않음
자동화 스크립트에 적합 보통 더 적합

실수로 API Key가 노출되었다면 즉시 OpenAI Platform에서 삭제하거나 다시 생성하세요.

API Key 로그인은 자동화에 편리하지만 API 사용량에 따라 과금됩니다. 초보자는 요금 규칙을 모른 채 장시간 작업을 실행하지 마세요.
